# Source credits

Porpoise by elripalda and its existing contributors remains the original application. Preserve the root CREDITS.md and LICENSE, including Dolphin and all existing third-party attribution.

The Move/Nav consumer was developed against the standalone Move Studio producer, based on AnyPad PS5 by sinfiltros/elmonomalvad0 and S-Mohammad-A's English fork. New consumer code is GPL-3.0-or-later, consistent with the source notices. The branch does not bundle the producer's Bluetooth keys/configuration or native SDK binaries.

Move report/calibration research references include thp/psmoveapi, nitsch/moveonpc and Linux hid-sony. The camera producer separately uses PS3EYEDriver/Linux gspca register references, libuvc and stb_image; these camera implementations are not linked into Porpoise by this patch.

PoorDS4, HearBridge, OmniPad, Owlmic, scrcpy and CamRelay were researched for related ownership, camera and runtime questions. No complete port of those projects is claimed here.

See [the detailed provenance ledger](../move-studio/CREDITS.md) for source URLs and dependency relationships. Verify obligations at the exact source revision when copying/linking code; research attribution is not a substitute for a dependency's license file.
